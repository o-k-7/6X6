# 6X6 plugin

6X6 puts the essential answer first and expands on request.

This is a skills-only package. It has no executable hooks, MCP server, provider client, telemetry, authentication, or network dependency.

After installation, ask the host to use 6X6. Installation makes the Skill available but does not make it an always-on default. The host may apply higher-priority instructions and safety policy.

Project documentation: https://github.com/o-k-7/6X6

Support: https://github.com/o-k-7/6X6/issues
