# Developer Certificate of Origin policy

6X6 uses the Developer Certificate of Origin (DCO) process for inbound contributions.

By adding a `Signed-off-by:` line to a commit, a contributor certifies that they have the right to submit the contribution under the project's license and the Developer Certificate of Origin 1.1.

Canonical DCO text: https://developercertificate.org/

## Required sign-off

Each contribution intended for merge should contain a sign-off matching the contributor identity used for the commit, for example:

```text
Signed-off-by: Jane Developer <jane@example.com>
```

Git can add this automatically:

```bash
git commit -s
```

A sign-off is not a copyright assignment. Contributors retain copyright in their contributions while licensing accepted contributions under the same outbound license used by the project unless a separate written agreement states otherwise.

Contributors must not submit code, prompts, documentation, evaluation data, model outputs, confidential material, or other content they do not have the right to contribute.
