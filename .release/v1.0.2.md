# 6X6 v1.0.2

**36 words first. Everything else on demand.**

Hardening release for task completion, host enforcement, evidence handling, and release safety.

## Highlights

- Adds provider-neutral host enforcement with persistent instruction placement, Signal validation, bounded repair retries, semantic-validation hooks, and fail-closed behavior.
- Keeps Expand and Full outside the strict Signal size gate.
- Prevents missing, blocked, not-run, duplicate, malformed, or partial evaluation evidence from becoming a full pass.
- Adds an eight-provider live-acceptance evidence gate without claiming unexecuted compatibility.
- Aligns installation, compatibility, security, privacy, legal, contribution, and release documentation.
- Keeps deterministic validation zero-cost and provider-neutral.

## Validation

The release publisher reruns the unit/regression suite, sample Signal checker, offline evaluation, security gate, and release consistency gate before publication.

## Compatibility claim

This release does **not** claim universal model compatibility or an independently executed 8/8 provider matrix. Named external-model compatibility requires recorded live evidence for the exact provider/model/host configuration.

## Versioning

The normative protocol remains version 1.0.0. Package/release metadata is v1.0.2.

## Cost

No paid 6X6 infrastructure, model API, hosted service, or runtime dependency is required for the deterministic release path. External live-model testing remains opt-in and provider-dependent.
