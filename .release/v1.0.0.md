# 6X6 v1.0.0

**36 words first. Everything else on demand.**

First stable public release of 6X6.

## Highlights

- 30-second copy/paste setup for normal chat users
- `INSTALL-WITH-AI.txt` for coding-agent installation
- Claude Code, Codex and Cursor Agent Skill packaging
- universal prompt fallback for other chat/model hosts
- Signal -> Expand -> Full progressive disclosure
- protected handling for code, URLs, exact values and safety-critical content
- zero-dependency conformance checker and offline evaluator
- repository security gate for credential-like material and forbidden Python execution/network capabilities
- public GitHub Actions CI on standard `ubuntu-latest`

## Validation

The public release path runs the full unit-test suite, sample Signal conformance, offline evaluation, security audit and release structure gate.

## Cost and privacy

6X6 requires no 6X6 account, API key, server, hosted database, telemetry service or paid infrastructure. Normal users only need the instruction/Skill files; Python tooling is for validation and maintainers.

## Known limitation

The deterministic reference word counter uses whitespace-separated words. Strict mechanical word counting is therefore not yet suitable for languages that do not normally separate words with spaces.
