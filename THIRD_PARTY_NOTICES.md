# Third-Party Notices

_Last reviewed: 2026-08-31._

6X6 currently has no required third-party runtime dependencies and does not vendor third-party source code, model weights, datasets, or binaries.

## Specifications and interoperability references

The project references the Agent Skills specification for interoperability. That specification and its tooling are maintained independently and retain their own terms.

The repository may mention AI products and developer tools in documentation or compatibility examples. Product names and trademarks remain the property of their respective owners.

## Optional external tools

A contributor may choose to use external tools such as Git, Python, GitHub, or an Agent Skills validator. Those tools are not bundled with 6X6 and retain their own licenses and terms.

## Contribution rule

Do not add copied prompts, source code, benchmark datasets, model outputs, images, or other third-party material unless its provenance and redistribution rights are documented and compatible with this repository.

If a future release vendors or requires third-party components, this file must be updated before release.
