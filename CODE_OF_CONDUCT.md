# Code of Conduct

6X6 welcomes constructive contributions from everyone.

## Expected behavior

Be respectful, specific, and focused on the work. Assume good intent, give actionable feedback, and make space for different communication styles and accessibility needs.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, deliberate disruption, and publication of another person's private information are not acceptable.

## Enforcement

Repository maintainers may edit, remove, or reject contributions and participation that violate these expectations. Serious or repeated violations may result in temporary or permanent exclusion from project spaces.

Reports should be made privately to the repository owner through an appropriate GitHub contact channel rather than posted publicly when they contain sensitive information.

## Scope

This code applies in repository discussions, issues, pull requests, reviews, and other project-managed spaces.
